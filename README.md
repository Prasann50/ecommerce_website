# 🛍️ ShopEase – Online Shopping Website

ShopEase is a responsive front-end **online shopping website** developed using **HTML5, CSS3, and JavaScript**. The project provides a simple and interactive shopping experience where users can browse products, search for products, add items to a cart, and manage their cart.

The project is designed as a front-end e-commerce prototype and uses **Browser Local Storage** to maintain cart information.

## ✨ Features

* 🏠 Responsive Home Page
* 🛒 Product browsing and shopping page
* 🔍 Live product search and filtering
* ➕ Add products to cart
* ➖ Remove products from cart
* 💾 Cart persistence using Local Storage
* 📱 Responsive design for different screen sizes
* 📩 Contact form
* 🚫 "No Product Found" message for unavailable searches
* 💳 Simulated checkout/order confirmation
* 🌙 Modern dark-themed user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, animations, and responsiveness
* **JavaScript (ES6)** – Dynamic functionality and user interactions
* **Local Storage** – Client-side cart data persistence

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/shopease.git
```

### 2. Open the Project

Open the downloaded project folder in **Visual Studio Code** or any preferred code editor.

### 3. Run the Website

Open the `index.html` file in a modern web browser such as:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

You can also use the **Live Server** extension in Visual Studio Code for easier development.

## 🛒 How to Use

1. Open the ShopEase home page.
2. Navigate to the **Shop** page.
3. Browse the available products.
4. Use the search bar to find a specific product.
5. Click **Add to Cart** to select a product.
6. Open the **Cart** page to view selected products.
7. Remove unwanted products if required.
8. Continue shopping or proceed to the simulated checkout.
9. Use the **Contact** page to submit a message.

## 💾 Local Storage

ShopEase uses the browser's **Local Storage** to save cart information.

This allows the selected products to remain in the cart even when the page is refreshed.

No backend database is used in the current version.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

The layout automatically adapts to different screen dimensions using responsive CSS techniques.

## 🔍 Search Functionality

The Shop Page provides a live search feature. When the user enters a product name, JavaScript dynamically filters the available products.

If no matching product is found, the website displays:

**"No Product Found"**

## 💳 Checkout

The current version includes a **simulated checkout process** for demonstrating the shopping workflow.

It does not include:

* Real payment processing
* Online transaction handling
* Payment gateway integration

## 🔐 Current Limitations

ShopEase is currently a front-end e-commerce project. Therefore, it does not include:

* Backend server
* Database
* User authentication
* Real payment gateway
* Admin dashboard
* Real order management
